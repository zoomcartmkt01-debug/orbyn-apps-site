# ORBYN TECH Apps

Static HTML/CSS for https://apps.lchnetmarketing.com, published from `main` at `/` by GitHub Pages. No framework, build step, analytics, tracking or executable JavaScript. The only script elements contain WebPage, SoftwareApplication and FAQPage JSON-LD.

## Validate

Python 3, standard library only:

```sh
python scripts/verify.py
python scripts/verify.py --source-root D:/ORBYN/CONTROL_TOWER/marketing
```

The second command also compares the archived policy Markdown with the original marketing files. Verification compares ordered visible policy wording after removing Markdown formatting and normalizing layout whitespace. Only publication-date placeholders are replaced: STCW policies use 20 October 2026; Site Measure Check uses 19 October 2026. Watt to Amp retains its source effective date, 21 October 2026, and literal numbered section headings. No other policy wording changes are permitted. Ordered list numbers are generated by HTML; bold, headings and line breaks are presentation.

`policy-sources/` preserves the original reviewed Markdown, including date placeholders and the original Draft filename. The published Site Measure Check policy is final for this task. Watt to Amp includes the three approved worked examples; validation checks the calculations and visible FAQ answers against JSON-LD. The Google Play URL remains an HTML comment until its approved store link is available.

## Hosting

GitHub Pages source: branch `main`, folder `/`. Custom domain: `apps.lchnetmarketing.com` (also stored in CNAME). DNS must point to the repository owner's GitHub Pages host. Domain DNS and account settings are managed by the Owner.
